# 万维文 WitWork

> **万维文 AI 写作 —— 汇万千思路，写一纸文章。**

一个**本地优先**的人机实时协作写作系统：AI 长篇写作 × 自有世界观知识库 × 跨章一致性管理，
全部在你自己的机器上完成。**离线可用，无云端参与，不上传任何数据。**

- 中文名 **万维文** · 英文名 **Wit Work Word**（简称 **WitWork**）
- 定位：给小说家的本地 AI 写作协作桌面应用

---

## 为什么是它

| | |
|---|---|
| 🔒 **数据不出本机** | 作品、设定、人物、密钥全部存在本地 SQLite 与配置文件里，断网照写。没有账号，没有同步，没有"服务器在维护"。 |
| 🧠 **为长篇而生** | 不是一次性聊天补全。人物状态、伏笔生命周期、时间线、地理规则会持续作用于后续每一章的生成与检索。 |
| 📚 **世界观真正参与写作** | 知识库分域收拢设定与素材，向量 + 关键词双路检索；嵌入模型缺失时自动降级，离线即开即用。 |
| 🖊️ **写作体验不将就** | 信纸横线、专注 HUD、逐稿历史与快照、统一全书标点的中文排版引擎——写字这件事本身被认真对待。 |

## 能力总览

### AI 写作

- **流式协作**：本地模型（如 Ollama）或任意 OpenAI 兼容服务，续写 / 润色 / 扩写 / 缩写 / 改写。
- **右键即写**：在正文里选中一段、右键选择**扩写 / 缩写 / 修改 / 续写**，AI 直接作用于选区。
- **大纲驱动成文**：写下想法 → AI 生成章节大纲 → 再据大纲扩写成完整正文。想先有骨架还是正文，都由你决定。
- **通读全书**：让 AI 读完整部作品，按"问题 → 位置 → 修改建议"给出可执行的修改意见。
- **默认协作助手**：内置「默认万维文」人格，可自由改写，也可用自然语言临时叠加人格 overlay。

### 一致性管理

- 人物卡自动按章节正文匹配出场；伏笔贯穿 planned → planted → resolved 全生命周期。
- 异写归一、爽点节奏分析、跨章搜索替换，防止写到后面忘了前面。

### 知识与素材

- 世界观 / 人物 / 势力 / 情节 / 地点 / 词条 / 素材分区管理。
- 支持嵌入模型的向量检索，也可在无模型时退化为关键词检索。

### 交付与保全

- **导出**：Word / Markdown / EPUB / 设定 MD·JSON / TXT，导出前经排版引擎修正标点、引号与段首缩进。
- **备份恢复**：一键打包数据库与配置；恢复前自动再打一份 `pre-restore` 备份，误操作可逆。

### 写作环境

- **功能面板（HUD）**：时钟、今日事项、日程倒计时、歌曲识别（Windows SMTC，含封面 / 旋律可视化 / 音量 / 换曲）、专注时长。
- **三态视图**：纯写作 / 手机稿预览 / 分屏，右上角一键切换。

## 三分钟上手

### 方式一：双击即用（推荐）

双击 `start.bat`：

1. 首次运行自动建立 Python 虚拟环境并安装依赖（需本机已有 `python`）；
2. 服务启动后自动打开浏览器到 `http://127.0.0.1:8723/`；
3. 再次双击只会新开一个标签页，不会拉起第二份服务。

停止服务：关掉 `start.bat` 打开的黑色窗口即可。

### 方式二：手动启动

```bash
venv\Scripts\python.exe -m server.main          # Windows
PYTHONPATH=. venv/bin/python -m server.main     # macOS / Linux
```

服务只监听 `127.0.0.1:8723`（本机）。

### 接入一个真正的模型

默认已种两个 Provider：**本地演示 (mock)**（离线假数据，用来熟悉界面）与 **本地 Ollama**（指向 `http://127.0.0.1:11434`）。

想用真实模型，先装好 [Ollama](https://ollama.com) 并拉取模型：

```bash
ollama pull qwen3:14b          # 综合最强，推荐
ollama pull qwen2.5:7b         # 轻量够用
ollama pull deepseek-r1:7b     # 偏推理
```

然后在「AI 助手」里选中对应 Provider、点「测试」，通过即可开始写。

## 从源码构建（可选）

仓库中的 `web/` 已是构建产物，可直接运行；如需自行重建：

```bash
cd web-astro
npm install
node_modules/.bin/astro build      # 产物输出到 web-astro/dist
python web-astro/deploy_astro.py   # 部署到 web/，由 FastAPI 托管
```

桌面版（Electron）打包见 `desktop/`，需先具备 `web/` 与 `venv/`。

## 目录结构

```
server/         FastAPI 后端 + SQLite（单一真源）+ 服务（SMTC、导出、备份…）
web-astro/      前端源码（Astro + Vue + Three.js），构建后由 FastAPI 托管
desktop/        Electron 桌面包装（electron-main / preload / 打包配置）
tools/          开发期脚本（冒烟测试、诊断、桌面快捷方式…）
使用说明.md      完整使用手册（界面、AI 协作、一致性工具、导出、备份、排障）
```

> 注：代码与目录内部仍沿用 `inkrealm` 作为工程标识（环境变量、数据库文件、打包资源路径），以保证构建与历史数据兼容；对外品牌统一为 **万维文 / WitWork**。
