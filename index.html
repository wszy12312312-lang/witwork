Why

为什么是它

市面上大多数 AI 写作工具在帮你写第 500 字时很好用，写到第 5 万字时就开始失忆。万维文从一开始就为长篇而生。

🔒

数据不出本机

作品、设定、人物、密钥全部存在本地 SQLite 与配置文件里，断网照写。没有账号，没有同步，也不会有「服务器正在维护」。

🧠

为长篇而生

不是一次性聊天补全。人物状态、伏笔生命周期、时间线、地理规则会持续作用于后续每一章的生成与检索。

📚

世界观真正参与写作

知识库分域收拢设定与素材，向量 + 关键词双路检索；嵌入模型缺失时自动降级为关键词方案，离线即开即用。

🖊️

写作体验不将就

信纸横线、专注 HUD、逐稿历史与快照、统一全书标点的中文排版引擎——写字这件事本身被认真对待。

Features

能力总览

从第一次灵感闪现，到最后一稿导出成书，整条链路上都有趁手的工具。

  • 流式 AI 协作 本地模型（如 Ollama）或任意 OpenAI 兼容服务，续写 / 润色 / 扩写 / 缩写 / 改写。
  • 右键即写 在正文里选中一段、右键选择扩写 / 缩写 / 修改 / 续写，AI 直接作用于你的选区。
  • 大纲驱动成文 写下想法 → AI 生成章节大纲 → 再据大纲扩写成完整正文。先有骨架还是先有正文，随你。
  • 通读全书 让 AI 读完整部作品，按「问题 → 位置 → 修改建议」给出可执行的修改意见。
  • 一致性管理 人物卡自动按章节正文匹配出场；伏笔贯穿 planned → planted → resolved 全生命周期。
  • 异写归一与节奏 异写归一、爽点节奏分析、跨章搜索替换，防止写到后面忘了前面。
  • 多格式导出 Word / Markdown / EPUB / 设定 MD·JSON / TXT，导出前经排版引擎修正标点、引号与段首缩进。
  • 备份与恢复 一键打包数据库与配置；恢复前自动再打一份 pre-restore 备份，误操作可逆。
Workspace

写作环境

安静，但什么都在手边。

三态视图

纯写作 / 手机稿预览 / 分屏，右上角一键切换。预览会按手机稿形态分页，写网文时心里有数。

时钟、今日事项、日程倒计时、歌曲识别（含封面 / 旋律可视化 / 音量 / 换曲）、专注时长。

逐稿可回溯

自动历史栈 + 手动快照，任意一步都能撤回；AI 落笔前也会先留一份，放心让它改。

Get started

三分钟上手

不需要注册，不需要配服务器，把仓库拉下来就能写。

  1. 双击 start.bat 首次运行自动建立 Python 虚拟环境并安装依赖；服务起来后自动打开浏览器到本机地址。再次双击只会新开一个标签页。
  2. 拉取一个本地模型 装好 Ollama 后拉取模型，然后在「AI 助手」里选中 Provider、点「测试」即可。
  3. 开始写第一章 写完几百字后，试着选中一段右键「扩写」，或者点大纲让 AI 先替你搭骨架。
